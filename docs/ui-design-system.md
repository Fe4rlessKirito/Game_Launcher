# UI design system

The desktop UI uses semantic tokens rather than product-specific names. `Colors.axaml`, `Typography.axaml`, `Spacing.axaml`, and `Controls.axaml` are the only places that should define palette, rhythm, typography, radii, and control sizing. Initial surfaces use a quiet dark navy, one electric accent, and an 8-point spacing rhythm. Artwork is decorative; readable status and actions are always available without it.
